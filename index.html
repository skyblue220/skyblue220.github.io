🎯 About Me

현재 응용화학과에 재학 중이며, 문제를 구조적으로 설계하고 구현하는 학습 방식이 제 사고 성향과 더 잘 맞는다고 판단하여 소프트웨어융합학과로의 전과를 희망하고 있습니다.

고등학생 시절 물리·화학 문제를 해결하는 과정에서, 주어진 수치와 조건 간의 관계를 분석하고 이를 하나의 구조로 정리하는 사고 과정에 흥미를 느껴왔습니다. 이러한 사고 방식은 대학 진학 이후에도 유지되었으며, 전공 수업과 개인 활동을 통해 점차 프로그래밍과의 유사성을 인식하게 되었습니다.

특히 프로그래밍은 문제를 구성하는 요소 간의 관계를 명확히 정의하고, 그 규칙이 일관되게 작동하도록 설계하는 학문이라는 점에서 제 사고 방식과 잘 맞는다고 느꼈습니다. 이에 따라 소프트웨어를 단순한 기술이 아닌 하나의 사고 체계로 인식하게 되었고, 이를 체계적으로 학습하고자 전과를 지원하게 되었습니다. 이러한 사고 방식이 실제로 어떻게 구현으로 이어졌는지를 보여주기 위해 아래의 프로젝트들을 포트폴리오로 정리하였습니다.

카드게임 카드 관리 프로젝트

프로젝트 배경

보드게임 동아리 활동 중 카드 데이터를 관리하고 공유하는 과정에서 반복적인 불편함을 느끼게 되었고, 이를 해결하기 위한 프로그램을 직접 설계·구현하였습니다.

설계 목표

카드의 외형이나 연출보다, 카드가 가지는 속성·효과·조건을 데이터 구조로 정의하는 데 집중하였으며, 향후 해당 구조를 기반으로 로직을 확장할 수 있도록 설계하는 것을 목표로 하였습니다.

구현 및 판단

카드 정보를 객체 단위로 관리하고, 카드풀마다 구성되는 구조를 설계하였습니다. 또한 프로젝트의 목적에 부합하지 않는 네트워크 기능은 과감히 배제하고, JSON 기반 데이터 공유 방식에 Base64 인코딩을 적용하여 문제 해결에 집중하였습니다. 이를 통해 기능을 많이 구현하는 것보다, 프로젝트의 목적에 맞는 구조를 선택하는 판단이 소프트웨어 개발에서 중요하다는 점을 체감하였습니다.

의미

이 프로젝트를 통해 다양한 기능들의 구현 자체보다, 문제의 본질을 정의하고 목적에 맞는 구조를 선택하는 것이 소프트웨어 개발에서 얼마나 중요한지 체감하게 되었습니다. 이 프로젝트는 수업 과제가 아닌 개인적인 문제 인식에서 출발하여, 스스로 구조를 설계하고 구현한 경험으로, 제가 소프트웨어적 사고에 흥미를 느끼는 방식이 일관되게 드러난 사례라고 생각합니다.

Unity 기반 과학 실험 시뮬레이션

프로젝트 배경

코로나19로 인해 실제 실험 수행이 어려운 상황에서, 실험 과정을 정리하고 이를 대체할 수 있는 과학 실험 시뮬레이션 프로그램을 기획하게 되었습니다. 저는 해당 프로젝트에서 팀장을 맡아 전체 계획을 수립하고, Unity를 활용해 시뮬레이션을 제작하였습니다.

구현 내용

Unity 엔진을 활용하여 두 명의 플레이어가 직접 과학 실험의 원리에 대해서 알아보거나, 과학 개념을 시각적으로 이해할 수 있도록 시뮬레이션을 구현하였습니다.

활용 및 결과

해당 프로젝트는 고등학생 프로그래밍 대회에 출품되어 발표 및 시연 자료로 활용되었으며, 아래 영상은 당시 사용된 시연 영상입니다.

의미

프로그래밍 가치관

문제를 정의하고, 구조로 해결하다

저는 문제를 구성하는 요소들 간의 관계를 정의하고, 그 규칙이 일관되게 작동하도록 구조를 설계하는 과정에서 가장 인상깊은 경험을 했습니다. 프로그래밍은 단순히 코드를 작성하는 행위를 넘어, 문제를 체계적으로 분석하고 해결책을 모색하는 도구라고 생각합니다.

전과라는 선택 역시 단순한 변심이 아닌, 이러한 사고 방식을 가장 효과적으로 발전시킬 수 있는 환경을 능동적으로 선택한 결과라고 생각합니다. 본 포트폴리오에 담긴 프로젝트들은 모두 문제를 정의하고 구조로 해결하려는 제 학습 태도가 실제 행동으로 이어졌음을 보여주는 사례입니다.
